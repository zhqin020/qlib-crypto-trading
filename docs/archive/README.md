## Why Archive?

Archived docs provide:
- ✅ Historical context for decisions
- ✅ Evolution of the codebase
- ✅ Debugging approaches that worked
- ✅ Lessons learned

But they are **NOT** current references.

## Using This Archive

**Good Uses**:
- "Why was this decision made?"
- "How did we solve this problem before?"
- "What was the development process?"

**Bad Uses**:
- Copy-paste code (may be outdated)
- Current feature reference (use main docs)
- Configuration examples (use current docs)

## Archive Maintenance

This archive is maintained by the development team:
- Review quarterly for new additions
- Consolidate related archives
- Update index with new insights
- Never delete (only move to archive)
